# Origin

## Why this repo exists

This repo opens the Language Atlas with a Go-native operator surface while staying inside the same Kinetic Gain OS story:

- regulated workflows
- ingestion reliability
- evidence lineage
- buyer-safe operator tooling

`regulatory-comment-intelligence-hub` focused on the review and approval layer. `gov-comment-ingestor` moves one tier earlier and makes the intake pipeline itself visible: source adapters, parser drift, attachment handling, queue freshness, and normalization trust.

## Public positioning

This is a vertical-specific operator dashboard portfolio repo, not a protocol-spec repo. It belongs in the Atlas / operator systems lane.
